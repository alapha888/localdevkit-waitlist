# LocalDevKit (working name) — waitlist validation page

A planned native macOS developer toolbox (Windows later as a separate native build): offline tools for AI-coding data tasks — streaming viewer/search for very large JSON & log files, cURL conversion, local redaction of secrets in logs/JWTs, LLM token counting, and related helpers picked by registrants. Planned $19 one-time.

- Validation page: https://alapha888.github.io/localdevkit-waitlist/
- Status: product not built. This repo contains only the validation page — no product source code.
- Decision rule: registrations ≥30 by 2026-10-31 → start building (native macOS first; Windows as a separate native build, registrations split by system); below that, drop the idea and notify registrants by email.
- Indicative price (test parameter): $19 one-time. No payment taken, no pre-order.
- Demand evidence: desktop category scan 2026-10-10 — DevUtils author-disclosed ~$5,500/month in late 2023 (category-level paid evidence; the specific AI-coding cut has no independent revenue evidence, which is what the top-3 tool ballot in the registration email tests).
